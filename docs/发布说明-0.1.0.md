# 0.1.0 内部预览

首次整理的 Mac 串口助手：设备识别提示、短信卡片、原始日志、自动跟随、日志保存、文本与 HEX 手动发送，以及配置教程。

- macOS 13+；Universal arm64 / x86_64，Intel 尚未真机验证。
- App 使用 Developer ID Application: ZEAN LI (4BHPD976HX) 签名，启用 Hardened Runtime；Apple 公证尚未完成。
- 短信解析与推送日志关联具有固件和编码限制，详见 README。
- DMG 为内部验收用。正式公开前需完成公证、安装验收、隐私与素材来源复核。
- 仓库保持私有，Release 保持草稿。不提供公开下载，也未声明开源许可证。

下载后可在安装包目录执行 `shasum -a 256 -c SHA256SUMS` 校验文件。将 App 拖入 Applications 后按系统提示操作，不关闭系统安全保护。
