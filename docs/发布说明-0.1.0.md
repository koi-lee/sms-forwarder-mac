# 0.1.0 Build 2 预览（安装包修订 r2）

在 Mac 上通过 USB 查看已适配短信设备的短信、原始日志和推送状态，无需 Windows 虚拟机。项目代码采用 MIT 许可证。

## 下载哪个文件

- **当前版本：SMS-Forwarder-Mac-0.1.0-build2-r2-preview.dmg**，应用版本 0.1.0 (2)。
- **校验文件：SHA256SUMS-build2-r2**，与上述 DMG 放在一起使用。
- **INSTALL.zh-CN.md**：中文安装与系统拦截处理说明。
- r2 仅更新包内安装说明及快速上手，App 与已验收 Build 2 相同；没有 r2 的 Build 2 包保留供回退。
- 不带 build2 的 DMG 与 SHA256SUMS 是旧 Build 1 回退文件。
- Source code 压缩包供开发者使用，不是 App 安装包。

打开 DMG，把应用拖到 Applications，再从“应用程序”启动。普通用户无需安装 Xcode。完整步骤见[安装教程](https://github.com/koi-lee/sms-forwarder-mac/blob/main/docs/下载安装.md)，安装后按[第一条短信教程](https://github.com/koi-lee/sms-forwarder-mac/blob/main/docs/快速上手.md)验证。

## 使用前了解

- macOS 13+；Universal arm64 / x86_64，Intel 尚未真机验证。
- 有 Developer ID 签名和 Hardened Runtime，**尚未 Apple 公证**。出现系统阻止时按安装教程核对来源并单独允许打开，不关闭全局系统保护。
- 本机 Build 2 安装副本、USB 接收和 Bark 实际通知已对照通过；未验证互联网下载后的 Gatekeeper 放行体验。
- 需要独立短信硬件和 SIM 卡；解析与推送日志关联受固件、编码及并发事件影响，不保证所有短信宝兼容。
- 新增帮助菜单与关于信息，支持邮箱 service@starshoreai.com。

当前仓库仍私有，Release 为草稿，外部用户暂不能下载。公开前仍待隐私与素材来源审核及作者最终确认。
