# 0.1.0 Build 5 公证预览版

在 Mac 上通过 USB 查看已适配短信设备的短信、原始日志和推送结果。代码采用 MIT 许可证。

## 下载与安装

下载 **SMS-Forwarder-Mac-0.1.0-build5-notarized.dmg**，打开后将 App 拖到 Applications。配套校验文件为 **SHA256SUMS-build5**。

[完整安装教程](https://github.com/koi-lee/sms-forwarder-mac/blob/main/docs/下载安装.md) · [第一条短信](https://github.com/koi-lee/sms-forwarder-mac/blob/main/docs/快速上手.md)

## 本版变化

帮助菜单新增作者自愿打赏窗口，内含支付宝和微信二维码。打赏没有固定金额，也不影响下载或功能；扫码需使用另一部手机。App 不读取支付账户、不发起付款，也不联网报告扫码行为。用户选定的日志文件设有 100 MiB 上限，达到上限后停止追加，窗口继续显示。Build 4 起已移除可执行文件中的本机绝对编译路径并加入构建后检查，Build 5 延续这项检查。App 与 DMG 均完成 Developer ID 签名及 Apple 公证，DMG 附有安装与快速上手说明。

## 使用范围

- macOS 13+；Apple Silicon / Intel 双架构，Intel 尚未真机验证。
- 需要短信硬件、SIM 卡及 USB 数据线；不保证所有短信宝固件兼容。
- 短信卡片仅保存在本次运行内存中，日志需主动保存。
- Build 2 的设备短信和 Bark 接收已实测；Build 5 未新增硬件实测。
- 初次运行可能显示互联网下载确认。遇到损坏或恶意软件提示请核对来源并反馈，不关闭系统安全保护。
