# 构建与发布

当前预览版本 0.1.0 (Build 3)，macOS 13+，Apple Silicon / Intel 双架构。Intel 尚未真机验收。

## 构建

普通本地构建：`./build-app.sh`（ad-hoc 签名）。正式站外包：`./build-app.sh --developer-id`，精确使用 `Developer ID Application: ZEAN LI (4BHPD976HX)`。

正式配置启用 Hardened Runtime，关闭 `CODE_SIGN_INJECT_BASE_ENTITLEMENTS`。Build 2 曾因 get-task-allow 调试权限被 Apple 拒绝；Build 3 已修复，不要恢复该权限。签名核验通过不等于公证通过。

## 公证与打包

1. 执行工作台 `.apple-signing-policy/verify-all.sh`；2026/09/26 已全部通过。
2. 将已签名 App 用 ditto 打为 ZIP，使用 notarytool 提交并取得 Accepted。凭据由钥匙串提供，不写入源码或命令参数。
3. 下载公证日志核对 issues，再对 App 执行 stapler staple / validate。
4. 将 App、Applications 链接、安装说明与教程打包 DMG，使用同一 Developer ID 签名。
5. DMG 再提交公证，Accepted 后执行 staple / validate，检查 spctl 应用及 DMG 均接受。
6. 公证票据附加完毕后生成 SHA-256；校验值不可使用 staple 前的文件计算结果。
7. 通过隐私检查后，按作者授权推送、公开仓库并发布预览 Release，匿名下载复核校验值。
