# 构建与发布

## 构建

在装有 Xcode 的 macOS 上执行 `./build-app.sh`，得到本地 ad-hoc 签名的 App。要构建作者签名的站外包，执行 `./build-app.sh --developer-id`，精确要求 `Developer ID Application: ZEAN LI (4BHPD976HX)`。脚本构建 arm64 与 x86_64 Universal 二进制并核对签名身份，不自动使用其他证书。

当前内部预览版本 0.1.0，Build 2，macOS 最低版本 13。Build 1 安装包保留供回退。Intel 架构编译不等于 Intel 真机验收。本次不更改原有 Bundle ID，以避免与桌面已有应用产生配置迁移差异。

## 内部安装包

`dist/` 存放 App、DMG 与 SHA256SUMS，均不进入 Git 源码历史。包内包含 Applications 快捷方式和安装说明。当前包已签名，但尚未 Apple 公证，不作为面向普通用户的正式下载发布。

正式公证版发布前完成素材与隐私复核、签名政策检查、Apple 公证和 stapler 验证。作者已允许公证受阻时准备未公证预览版：明确标注限制并提供[下载安装教程](下载安装.md)，不把签名或本机实测当作公证。代码采用 MIT。GitHub 公开与 Release 发布仍在最终审阅阶段。
