# 飞书群通知配置说明

将设备收到的短信通知转发到自己管理的飞书群。此文为星岸 AI 整理的文字说明，不复制第三方教程图片；当前尚未完成本设备的飞书通道实测。

## 准备

- 使用有权限管理的群，确认组织允许添加自定义机器人。
- 设备固件需要支持飞书通道或相应自定义请求。Mac 串口助手仅用于观察日志。
- 先使用不含个人信息的测试短信，确认群成员范围适合接收通知。

## 配置步骤

1. 在飞书电脑端打开目标群，在群设置中查找“群机器人”，添加“自定义机器人”。若没有入口，检查群权限与组织设置，不要绕过管理员限制。
2. 设置机器人名称并保存 Webhook 地址。该地址具有发送消息的能力，不要放进公开截图、仓库或问题反馈。
3. 按飞书当前界面选择安全设置，并核对设备固件是否支持。关键词必须能匹配实际推送内容；签名校验需要固件生成对应签名。不要为了通过测试直接关闭既有安全设置。
4. 登录设备管理后台，选择固件提供的飞书通道，按实际字段填写机器人地址与所需安全参数，保存。不同固件字段不同，本文不假设仅粘贴 Webhook 就能工作。
5. 向设备 SIM 发送“飞书渠道测试01”。在目标群确认是否收到，并比对内容、发送号码与时间。
6. 如有问题，通过 USB 连接 Mac 串口助手，查看发送请求后的日志。HTTP 成功不一定代表业务成功，需结合响应内容和群内实际消息判断。

## 排查与验收

- 没有收到：先核对设备网络、机器人地址和安全设置；不要公开完整请求地址。
- 配置字段不匹配：记录设备型号与固件版本，联系硬件提供方核对通道能力。
- 保存证据：记录日期、固件、结果和脱敏截图。本项目尚未实测，不能把本文当作已验证的兼容清单。
