# SMS Forwarder Mac

[简体中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Español](README.es.md)

SMS 転送デバイス向けの macOS ネイティブ・シリアルモニターです。USB 接続で、対応する SMS の記録、動作ログ、通知の送信結果を確認できます。Windows 仮想マシンは不要です。

## Windows をお使いの方へ

[機器の説明書](https://my.feishu.cn/docx/QgfudtgpPobjvsxliVlcDkR9nod)の「4.1 硬件准备」にある「串口工具」欄から、添付ファイル `my_uart_V2.1.rar` を確認できます。

Windows 用ツールは機器提供元が提供・管理しています。本プロジェクトはリンクのみを掲載し、配布ファイルの保管や動作・互換性の検証は行っていません。飛書へのログインや閲覧権限が必要な場合があります。開けない場合は機器の販売元にお問い合わせください。

## 主な機能

- シリアルポートを検出し、USB 情報から ESP32 の可能性があるデバイスを表示します。この表示は互換性を保証しません。
- ログのリアルタイム表示、最新ログへの追従、文字サイズの調整、任意のファイル保存。
- 対応する SMS を直近 100 件まで表示。送信元番号、本文、送信日時、デバイスの IP アドレス、関連する通知ログを確認できます。最新の SMS への自動追従と移動に対応します。
- テキストまたは HEX バイトを手動送信し、必要に応じて CRLF を追加できます。AT コマンドは自動送信しません。

## 動作条件と制限

macOS 13 以降、データ転送対応の USB ケーブル、macOS が認識するシリアルポートが必要です。通信設定は 8-N-1、対応ボーレートは 9600、19200、38400、57600、115200、230400 です。

実機確認の対象は今回使用した ML307 シリーズの WIFI 転送デバイスです。ML307A / ML307C の全ファームウェアを確認したわけではありません。SMS 解析は、数字の送信元番号を持つ UCS-2 の SMS-DELIVER PDU に対応します。長文 SMS の分割部分は結合しません。着信は生ログで確認でき、不在着信専用カードはありません。

通知結果は、その後 60 秒以内のログと関連付けます。SMS や通知チャンネルが同時に動く場合は、生ログで確認してください。「成功」の表示だけではスマートフォンへの到着を証明できません。Bark は今回の実機で受信を確認済みです。他のチャンネルの説明は参考資料です。通知の転送はデバイスのファームウェアが独立して行います。

SMS カードは起動中のメモリにのみ保存されます。必要なログは明示的に保存してください。アプリには現在、ネットワークへのアップロードやテレメトリーの実装はありません。ただし、シリアルログや PDU には個人情報が含まれることがあります。

## 使い始める

1. 使用権限のあるデバイスを USB データケーブルで Mac に接続し、同じポートを使う他のソフトを閉じます。
2. 一覧を更新してポートを確認します。複数のデバイスがある場合は、抜き差し前後の一覧を比較します。
3. デバイス指定のボーレートを選び、接続します。今回の実機では 115200 を使用しました。
4. デバイスの SIM にテスト SMS を送り、SMS カードと通知ログを確認します。スマートフォンでの受信も確認してください。
5. 必要なログを保存し、終了時に切断します。通常の転送に必要なのは電源とネットワークで、Mac への常時接続は不要です。

## ビルドと資料

Xcode と macOS SDK をインストールし、リポジトリのルートで実行してください。既定のビルドは ad-hoc 署名です。Developer ID 署名と Apple の公証は別の手順で、公証は未実施です。

```sh
./build-app.sh
open dist/WIFI转发宝串口助手.app
```
