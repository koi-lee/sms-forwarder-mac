# 隐私与参考来源

当前 App 源码通过本机串口读取数据，未实现网络上传或遥测。短信卡片为内存数据；用户选择保存日志后，串口数据持续写入指定的本地文件。设备固件发送到 Bark 或其他渠道的数据由设备与所选服务处理，不受本 App 的本地存储边界覆盖。

本仓库仅纳入源代码、应用图标和已处理的教程配图。原始截图、原始串口日志、短信 PDU、设备密码和推送密钥保留在仓库外。教程图片的实色遮盖为隐私处理，不代表应用的真实界面内容。

教程参考用户提供的 WIFI 转发宝说明书及各渠道教程。链接副本的归属不等于重新取得原文版权，云端图片也尚未完成本项目的隐私审阅。公开前需检查转载范围、署名和访问权限。
