# 下载与安装

适用于 macOS 13 或更新版本。当前预览版为 0.1.0 (Build 6)，使用 Developer ID 签名并完成 Apple 公证。Intel 架构已编译，尚未 Intel 真机验收。

## 下载哪个文件

打开[Build 6 发布页](https://github.com/koi-lee/sms-forwarder-mac/releases/tag/v0.1.0-preview.6)，展开 Assets（附件）：

- 下载 `SMS-Forwarder-Mac-0.1.0-build6-notarized.dmg`。
- `SHA256SUMS-build6` 用于检查下载是否完整。
- Source code 压缩包供开发者使用，不是安装包。普通用户无需安装 Xcode。

## 安装并打开

1. 双击 DMG，将「WIFI转发宝串口助手.app」拖到 Applications（应用程序）。已有版本时先退出旧应用，保存需要的日志。
2. 从“应用程序”打开。首次可能提示“从互联网下载，是否打开”，核对应用与下载来源后点“打开”。
3. 在屏幕顶部应用菜单打开“关于 WIFI 转发宝串口助手”，确认版本为 0.1.0 (6)。
4. 按[第一条短信教程](快速上手.md)连接设备，再从手机向设备 SIM 卡发送测试短信。不要在串口“手动发送”框里输入测试短信。

## 核对下载文件

将 DMG 和校验文件保留原文件名，放在同一文件夹。若都在“下载”文件夹，在 Mac 自带“终端”依次执行：

```sh
cd ~/Downloads
shasum -a 256 -c SHA256SUMS-build6
```

预期出现文件名和 `OK`。提示 `No such file` 时检查路径及是否下载后多了 `(1)`；出现 `FAILED` 时停止安装并重新下载。

其他文件夹：在终端输入 `cd `（末尾有空格），从 Finder 把文件夹拖入终端，按回车后再执行校验命令。

## 被系统阻止或提示损坏

当前 Build 6 已公证，正常情况下无需关闭安全保护或手动移除隔离属性。若提示“无法检查恶意软件”，先确认下载的是 Build 6，而不是旧 Build 1/2、源码压缩包或第三方重新打包文件。

若提示“已损坏”“将损坏电脑”或签名异常，请停止打开，核对 SHA-256、重新从本项目下载，仍失败则反馈提示截图。不要用关闭 Gatekeeper 的命令绕过错误。受组织管理的 Mac 可能有额外安装限制，请联系管理员。

反馈请提供 macOS 版本、应用版本及脱敏截图，发至 service@starshoreai.com；不要发送密钥、完整手机号或原始 PDU。

## 验证范围

Build 6 修复了 DCS=0 英文短信正文解析；本机已实测纯英文及中日韩混合短信，Mac 正文与手机 Bark 接收均通过。长短信仍分段展示，不自动合并；其他编码及语言移位表尚未支持。Apple 公证与 Gatekeeper 检查也不等于所有 Mac、固件和网络环境都已测试。

参考 [Apple：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。
