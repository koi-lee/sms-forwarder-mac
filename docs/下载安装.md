# 下载与安装（未公证预览包）

适用于 macOS 13 或更新版本。当前 Build 2 已通过本机安装副本、USB 短信接收和 Bark 对照验证；Intel 尚未真机验证。安装包已有 Developer ID 签名，但尚未经过 Apple 公证。

当前仓库仍私有，Release 仍为草稿，外部用户暂不能下载。以下流程用于作者审核通过、预览 Release 正式发布之后。

## 下载并安装

1. 打开 [项目 Releases](https://github.com/koi-lee/sms-forwarder-mac/releases)，选择标明预览版本的发布记录。
2. 展开发布记录底部的 Assets（附件），下载 `SMS-Forwarder-Mac-0.1.0-build2-preview.dmg` 与 `SHA256SUMS-build2`。不要把自动生成的 Source code 压缩包当作安装包。
3. 将两份文件放到同一文件夹，按下方“核对下载文件”检查。带 `build2` 的 DMG 是当前验收版本；不带它的是旧 Build 1 回退包。
4. 双击 DMG，把 `WIFI转发宝串口助手.app` 拖到 Applications，再从“应用程序”启动。已有版本时先退出旧应用，保存需要保留的日志。
5. 在屏幕顶部应用菜单打开“关于 WIFI 转发宝串口助手”，确认版本为 0.1.0 (2)。随后按[第一条短信教程](快速上手.md)连接设备并验证。

## 核对下载文件

这一步用来检查下载是否完整，不需要安装开发工具。打开 Mac 自带的“终端”。如果两份文件都在默认“下载”文件夹，依次执行：

```sh
cd ~/Downloads
shasum -a 256 -c SHA256SUMS-build2
```

预期出现安装包文件名及 `OK`。如果存在重名下载（如文件名多了 `(1)`），请将两份文件放入一个新文件夹并保留原始文件名，再进入该文件夹校验。其他文件夹可在终端输入 `cd `（末尾有空格），从 Finder 把文件夹拖入终端后按回车，再运行第二行。

提示 `No such file` 时检查位置和文件名；出现 `FAILED` 时不要安装，请重新下载。校验只能核对文件一致性，不能代替来源核对或 Apple 公证。

## macOS 提示无法验证开发者或未检查恶意软件

先核对下载来自本项目 Release，以及发布记录明确说明尚未公证。只有确认来源可信、愿意使用预览版本时，才按 Apple 官方方法为此应用单独允许打开：

1. 尝试打开应用，关闭提示框。
2. 打开“系统设置 → 隐私与安全性”，向下找到该应用的阻止记录。
3. 若提供“仍要打开”，由你本人点击，按提示认证并确认打开。系统版本不同，文案可能略有差异。

不要关闭全局 Gatekeeper，不要运行移除隔离属性或关闭安全检查的命令。如果提示“将损坏电脑”、恶意软件、签名无效或文件损坏，请停止操作，保留提示并联系支持。受组织管理的 Mac 可能不允许单独放行，需联系管理员。

若没有“仍要打开”入口，或你不希望手动放行，请等待公证版本；也可按 README 从源码本地构建。源码构建需要 Xcode，不作为普通用户的默认安装方式。

## 常见问题

- 找不到设备：确认线缆支持数据传输，重新插入并点击刷新；推荐标签仅根据 USB 信息推测设备身份。
- 端口被占用：退出其他串口软件，避免同时运行多份本工具。
- 没有收到短信：先确认设备接收与网络状态，再查原始日志；本工具不替代设备固件推送。
- 反馈问题：发送 macOS 版本、应用版本、设备型号和遮盖隐私后的提示截图到 service@starshoreai.com。不要发送密钥、完整手机号或原始 PDU。
