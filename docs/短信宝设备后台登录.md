# 短信宝设备后台登录

来源：设备卖家提供的《WIFI转发宝-说明书》（用户于 2026-10-02 提供的飞书导出 PDF；原文链接见下方）。以下步骤根据说明书“手机配网”章节整理。

## 登录步骤

1. 给短信宝通电，等待约 10 秒，在 Wi‑Fi 列表中查找设备热点。说明书正文提到 `ESP32-AP-xxxxxx`，后缀因设备而异；同一章节另有一处写 `SMS-Forwarder-AP`，因此热点名称可能随固件/版本不同。
2. 在手机或电脑的 Wi‑Fi 设置中连接该热点。说明书示例显示热点为开放网络，无需输入 Wi‑Fi 密码。
3. 连接热点后打开浏览器，在地址栏输入 `http://192.168.4.1`。
4. 在设备登录页输入卖家说明书截图中列出的出厂默认账号和密码。为避免把默认凭据另行复制到项目文本，具体值请直接查看原说明书截图。
5. 登录后选择家里的 Wi‑Fi 并配置连接。说明书特别要求路由器使用 **2.4 GHz** Wi‑Fi；5 GHz 网络不能用于此设备配网。

## 找不到设备热点时

- 先确认手机/电脑 Wi‑Fi 列表里搜索过 `ESP32-AP-` 和 `SMS-Forwarder-AP` 两种名称。
- 说明书写明：设备成功连上家用 Wi‑Fi 后会关闭 `ESP32-AP-xxxxxx` 热点；若连接不上家用 Wi‑Fi，则会再次广播该热点。因此已完成配网时搜不到热点可能是正常现象。
- 如需重新进入配网，说明书建议暂时关闭家里的 Wi‑Fi，使设备连不上路由器，再等待它重新广播热点。完成设置后恢复家用 Wi‑Fi。不要先恢复出厂设置或刷固件。
- 如果临时关闭家用 Wi‑Fi 后仍找不到热点，可断电重启短信宝，等待约 10 秒并再次查找上述两种名称；仍无热点时记录设备指示灯状态并联系卖家核实该硬件/固件的配网模式。
- 如果后台打不开，确认仍连接设备热点，再访问 `http://192.168.4.1`。
- 如果保存家用 Wi‑Fi 后设备无法联网，检查家用网络是否提供 2.4 GHz 频段。
- 说明书同时包含卖家演示视频链接：[哔哩哔哩视频教程](https://www.bilibili.com/video/BV1GcxHBBEwR/?vd_source=25b81955a369a)。
