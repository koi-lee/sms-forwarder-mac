# 商家试用与推荐说明

帮助使用短信宝类设备的 Mac 买家，通过 USB 查看设备日志和支持的短信记录，无需安装 Windows 虚拟机。第三方免费开源工具，由 Koi / 星岸 AI 维护，与设备商家、运营商及 Bark 官方无隶属关系。

## 买家快速上手

1. 使用 macOS 13 或更新版本。安装包包含 Apple Silicon / Intel 两种架构；Intel 尚未真机验收。
2. 下载 DMG，将 App 拖入 Applications 后打开。不要关闭系统安全保护。
3. 按卖家说明完成设备配网、SIM 与推送设置，用支持数据传输的 USB 线连接 Mac。
4. 核对串口，按设备说明选择波特率（本次已适配设备为 115200、8-N-1），点击“连接并监听”。
5. 从手机向设备 SIM 发一条自编测试短信，分别核对 Mac 正文、设备推送日志与手机 Bark 是否真正收到。“手动发送”是串口指令入口，不是短信输入框。
6. 结束时断开串口。设备正常转发无需 Mac 助手一直运行；退出助手不保留短信卡片，日志需主动保存。
